## Быстрая установка

Выберите **один способ** для своей системы. Полный плагин объединяет все **34 авторских маркетинговых навыка**. CLI `npx skills` устанавливает те же навыки как отдельные папки, без регистрации плагина. 14 сторонних инженерных навыков — отдельное необязательное дополнение.

### Полный плагин

**Claude Code** — введите в чате Claude Code по очереди:

```text
/plugin marketplace add LuCheremisina/marketing-skills
/plugin install marketing-skills@cheremisina-marketing
```

**Codex CLI** — выполните в терминале:

```sh
codex plugin marketplace add LuCheremisina/marketing-skills
codex plugin add marketing-skills@cheremisina-marketing
```

В Codex с интерфейсом плагинов откройте **Plugins → Add plugin marketplace**, укажите `LuCheremisina/marketing-skills`, затем установите **Marketing Skill Cheremisina**. Если ваша версия не поддерживает этот пункт или команду, используйте установку Skills ниже.

**Claude / Cowork** — откройте **Customize → Plugins → Add → Add marketplace → Add from a repository**, укажите `https://github.com/LuCheremisina/marketing-skills`, затем выберите плагин и установите. Альтернатива — загрузить [ZIP всех 34 навыков](https://github.com/LuCheremisina/marketing-skills/releases/download/v2.0.7/marketing-skills-plugin-2.0.7.zip) через **Upload a plugin**.

**ChatGPT** — скачайте тот же ZIP и передайте его **Plugin Creator** с просьбой создать приватный персональный плагин; откройте полученную страницу и установите его. Нужен доступный в аккаунте интерфейс Plugins / Plugin Creator. Простое вложение ZIP в обычный чат не устанавливает плагин. [Подробная русская инструкция по системам](docs/INSTALL-PLUGIN.ru.md).

### Все 34 навыка через CLI: Codex, Claude Code, Cursor

Требуются **Node.js 22.20+ и Git**. Выполните строку для своей системы:

| Система | Все маркетинговые навыки во всех проектах пользователя |
|---|---|
| Codex | `npx skills add LuCheremisina/marketing-skills --skill '*' -a codex -g -y` |
| Claude Code | `npx skills add LuCheremisina/marketing-skills --skill '*' -a claude-code -g -y` |
| Cursor | `npx skills add LuCheremisina/marketing-skills --skill '*' -a cursor -g -y` |

`--skill '*'` выбирает весь обнаруженный набор; кавычки обязательны, чтобы оболочка не подставляла имена файлов. `-a` задаёт систему, `-g` — установку для пользователя во всех проектах, `-y` — без вопросов. **Для одного проекта уберите `-g`** и запустите команду из его папки. Не используйте `--all`, если нужен только один клиент: этот флаг выбирает также всех агентов.

Для интерактивного выбора навыков и систем:

```sh
npx skills add LuCheremisina/marketing-skills
```

### Один навык отдельно

```sh
npx skills add LuCheremisina/marketing-skills --skill che-deep-research
```

Выберите систему, если CLI предложит. По умолчанию это установка в текущий проект. Для глобальной установки, например в Codex, добавьте `-a codex -g`. [Отдельный ZIP Deep Research](https://github.com/LuCheremisina/marketing-skills/releases/download/v2.0.7/che-deep-research-3.0.0.zip) можно импортировать через поддерживаемый интерфейс Skills.

### Попросить агента установить

Вставьте в Codex, Claude Code или Cursor с доступом к терминалу:

```text
Установи все 34 маркетинговых навыка из LuCheremisina/marketing-skills
для своей системы, глобально. Используй:
npx skills add LuCheremisina/marketing-skills --skill '*' -a <свой ID: codex, claude-code или cursor> -g -y
Сначала замени <...> на ID своей системы. Если Node.js или Git отсутствует,
сообщи, что нужно установить. Если уже есть локально изменённые копии,
сначала покажи различия и сохрани их. После установки проверь список
навыков и доступ к ресурсам che-deep-research. Сообщи, что проверено.
```

Плагин и CLI — альтернативные способы: не включайте одновременно две копии одного набора. Локальная установка не переносится автоматически в облачный сеанс; установите навыки в среде, где работает агент. [Проверяемая установка фиксированного выпуска и откат](docs/INSTALL.ru.md#проверяемая-установка).

## Как пользоваться

После установки откройте новый чат или сессию. При необходимости включите плагин в списке установленных. Выберите навык в интерфейсе или попросите его применить:

```text
Примени che-deep-research. Сравни три сервиса автоматизации маркетинга
для B2B-компании. Рынок — Россия, горизонт решения — 12 месяцев.
Нужны источники, таблица сравнения, ограничения и рекомендация.
Сначала уточни недостающие вводные.
```

В **Claude Code после установки плагина** доступен вызов с пространством имён:

```text
/marketing-skills:che-deep-research Сравни три сервиса автоматизации маркетинга для B2B-компании
```

В **Codex после установки Skills через CLI** можно указать навык явно:

```text
$che-deep-research Сравни три сервиса автоматизации маркетинга для B2B-компании
```

В Cursor используйте выбор Skills или запрос по имени; в ChatGPT выберите установленный плагин и напишите задачу. Универсальный запрос «Примени che-deep-research…» подходит и для других поддерживаемых систем; формат slash-команд зависит от клиента.

Укажите бизнес, цель, аудиторию, географию, период, источники и формат результата. Можно приложить бриф и дать путь к файлу. Для рекламы, Wordstat, Метрики и email нужны отдельные подключения или разрешённые выгрузки: установка навыков сама их не создаёт. [Подключение источников](docs/MCP-CONNECTIONS.md).

### Проверить, обновить или удалить

Для Skills, установленных через CLI:

```sh
npx skills list -g
npx skills check
npx skills update che-deep-research -g
npx skills remove che-deep-research -g
```

Обновление всего глобального набора CLI, включая навыки из других источников: `npx skills update -g`. Для проектной установки используйте `npx skills list`, `npx skills update -p` и удаление без `-g` в папке проекта. Сохраните свои изменения перед обновлением.

Для нативного плагина используйте управление Plugins, а не `npx skills update`. [Обновление и удаление плагина](docs/INSTALL-PLUGIN.ru.md#обновление-и-удаление). После установки проверьте список 34 навыков, чтение одного справочного файла и пробную задачу; наличие файлов ещё не подтверждает выполнение всех сценариев.

## Качество и сопровождение

Факты, гипотезы, рекомендации и измеренный эффект разделены. При отсутствии данных навык сообщает ограничение. Исследования сохраняют источник, дату и область применимости. Публикация и внешние действия выполняются по явному разрешению пользователя.

Подготовка выпуска включает YAML-парсер, проверку ресурсов и авторства, сканирование публичных файлов, контрольные суммы и воспроизводимые архивы. Для выбранного навыка используйте [проверку качества](docs/EVALUATION.md) и синтетические примеры. Эти проверки не доказывают полное выполнение в вашей системе.

Проверка публичных первоисточников запланирована **1-го числа в 00:00, Asia/Novosibirsk**, с правами только на чтение. Изменения проходят проверку; автоматического слияния, установки или выпуска нет. Между проверками возможно отставание от первоисточников. [Правила сопровождения](docs/GOVERNANCE.md) · [Журнал изменений](CHANGELOG.md).
