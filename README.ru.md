## Быстрая установка

При наличии **Node.js 22.20+ и Git** выполните команду в папке проекта:

```sh
npx skills add LuCheremisina/marketing-skills --skill che-deep-research
```

Если появится выбор клиента, укажите свою систему. Затем попросите AI применить `che-deep-research` к вашему вопросу. [Пример запроса](docs/use-cases/deep-research.md#русский-пример). Можно начать с ZIP: [Deep Research 2.0.0](https://github.com/LuCheremisina/marketing-skills/releases/download/v2.0.1/che-deep-research-3.0.0.zip) и [инструкция импорта](docs/INSTALL.md#zip-and-plugin-installation).

По умолчанию CLI устанавливает навык в текущий проект. Для существующих установок и фиксированного выпуска с контрольными суммами используйте [проверяемую установку](docs/INSTALL.md#verified-installation). Быстрый путь проверен с CLI `skills` 1.7.0; он не подключает аккаунты и не подтверждает выполнение всех сценариев.

## Качество и сопровождение

Факты, гипотезы, рекомендации и измеренный эффект разделены. При отсутствии данных навык сообщает ограничение. Исследования сохраняют источник, дату и область применимости. Публикация и внешние действия выполняются по явному разрешению пользователя.

Подготовка выпуска включает YAML-парсер, проверку ресурсов и авторства, сканирование публичных файлов, контрольные суммы, воспроизводимые архивы и тестирование установки/отката. Для 34 авторских навыков подготовлены [81 фактический текстовый ответ на синтетические сценарии и повторные проверки](evals/cases-and-responses.json). Их оценивал один независимый Codex-проверяющий в общем контексте; это не 81 независимый запуск приложения. [Ограничения проверки](docs/EVALUATION.md) указаны отдельно.

Внешние источники проверяются **1-го числа в 00:00, Asia/Novosibirsk**. GitHub Actions проверяет публичные источники и кандидаты с правами только на чтение; полный результат сохраняется в логах. Локальная задача Codex сначала сопоставляет приватные и установленные копии, затем повторяет проверку публичных источников в свежем клоне и готовит PR через существующую авторизацию GitHub CLI после проверки лицензий и обезличивания. Ручное создание PR продемонстрировано; будущий запуск по расписанию с изменениями ещё не проверен. Ни один маршрут не выполняет слияние, выпуск или установку. Актуальность подтверждается на дату проверки, между проверками возможно отставание. У изменённого пакета должна быть новая версия.
