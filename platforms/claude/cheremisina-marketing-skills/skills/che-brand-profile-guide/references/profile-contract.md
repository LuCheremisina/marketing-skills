# Входной бренд-профиль

Поля: project_id; audience; positioning; primary_offer; approved_claims (значение, источник, дата, допустимый контекст); tone; prohibited_phrases; palette; typography; logo_asset; design_tokens; example_artifacts; publication_targets.

Профиль живёт в текущем проекте или передаётся пользователем. В библиотеку навыков он не записывается. Проверить происхождение и актуальность; противоречия показать до внешнего использования. Пустое поле не заполнять фактами другого бренда. Визуальные допущения можно предложить как черновик, бизнес-факты — нельзя.
