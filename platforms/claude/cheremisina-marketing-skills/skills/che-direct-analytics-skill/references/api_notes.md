# API — особенности и лимиты

## Яндекс.Директ

### Токены и доступ
- OAuth токен: https://yandex.ru/dev/direct/doc/dg/concepts/auth-token.html
- Для агентских кабинетов: в `Client-Login` указывать логин клиента, не агентства
- Токен действует 1 год; при ошибке 401 — обновить токен

### Reports API (статистика)
- Асинхронный: сначала создаёт отчёт (201/202), затем отдаёт данные (200)
- Время ожидания: от 5 до 120 секунд в зависимости от объёма
- Лимит: 5 одновременных отчётов на кабинет
- Максимальный период в одном запросе: 90 дней
- Максимум строк в отчёте: 1 000 000
- Данные за сегодня недоступны (только за завершённые дни)

### Campaigns API
- Лимит: 1000 кампаний на запрос (используй `Offset` для пагинации)
- Статусы: `ON` / `OFF` / `SUSPENDED` / `ENDED` / `ARCHIVED`

### Конвертация денег
- По умолчанию API возвращает деньги в микрорублях (× 10^6)
- Заголовок `returnMoneyInMicros: false` → деньги в рублях (рекомендуется)
- НДС: `IncludeVAT: NO` → цифры без НДС

## Яндекс.Метрика

### Токены
- OAuth токен: https://yandex.ru/dev/metrika/doc/api2/concept/authorization.html
- Доступ к счётчику: пользователь с токеном должен иметь права на счётчик

### Stat API v1
- Базовый URL: `https://api-metrika.yandex.net/stat/v1/data`
- Лимит: 10 запросов в секунду
- Максимум dimensions: 10, metrics: 20
- Максимум строк: 100 000 (используй `limit` + `offset` для пагинации)
- Период: до 2 лет в одном запросе

### Ecommerce данные
- Требуется настроенный модуль электронной торговли в счётчике
- Метрики: `ym:s:ecommercePurchases`, `ym:s:ecommerceRevenue`
- Если метрика = 0 — проверить настройку ecommerce в Метрике

### UTM-фильтрация
- Используй одновременно `ym:s:UTMSource=='yandex'` и `ym:s:UTMMedium=='cpc'`.
- `UTM_SOURCE` и `UTM_MEDIUM` задаются в config проекта; не подменяй их
  универсальным фильтром `cpc`.
- Для дневого кэша добавляй `ym:s:date` в dimensions, запрашивай все страницы
  и сохраняй пустой завершённый день как валидный факт.

## Частые проблемы

| Проблема | Причина | Решение |
|----------|---------|---------|
| Reports API зависает | Слишком большой период | Разбить на периоды до 30 дней |
| Данные Метрики не совпадают с Директом | Разная атрибуция | Метрика — последний клик, Директ — клик рекламы |
| Неатрибутированная e-commerce выручка | Нет или сломаны UTM-метки в Директе | Проверить шаблоны UTM; не распределять выручку по расходу |
| 0 конверсий в Метрике | ecommerce не настроен | Подключить DataLayer или Metrika ecommerce |
| 401 Unauthorized | Токен истёк | Перевыпустить OAuth-токен |
| 429 Too Many Requests | Превышен лимит запросов | Добавить `time.sleep(1)` между запросами |
