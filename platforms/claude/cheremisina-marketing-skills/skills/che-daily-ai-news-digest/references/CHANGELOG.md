# История версий Daily AI News Digest

Этот файл фиксирует траекторию развития агента — все изменения, мотивацию и эффект каждой версии.

---

## v5 — 2026-03-31

**Мотивация:** В сводке обнаружены кросс-источниковые дубли (одна тема из TechCrunch и The Decoder), а также факты «добора» до 10 новостей за счёт перефразировок.

| Изменение | Детали |
|---|---|
| **Усиленная дедупликация внутри пачки** | Добавлены 3 критерия для `dedup_within_batch`: fuzzy ≥ 0.55, Jaccard ≥ 0.40, сущностное совпадение (2+ из KEY_ENTITIES при Jaccard ≥ 0.25). При дубле сохраняется новость из более авторитетного источника (по `SOURCE_WEIGHTS`). |
| **Послабляющий критерий** | Если уникальных новостей < 10 после дедупликации, LLM получает инструкцию «ровно N новостей» вместо «строго 10». Не добивать до 10 за счёт повторов. |
| **Константы** | Добавлены `BATCH_FUZZY_THRESHOLD = 0.55`, `BATCH_JACCARD_THRESHOLD = 0.40`, список `KEY_ENTITIES`. |
| **История запусков** | Добавлен механизм автозаписи в `data/run_history.jsonl` при каждом запуске. |

**Файлы:** `scripts/collect_and_send.py`, `references/CHANGELOG.md`, `SKILL.md`

## v4 — 2026-03 (ранее)

**Мотивация:** Военно-политические и инвестиционные новости проходили в сводку через LLM-фильтр. Подписчики получали нерелевантный контент. Также требовался более красивый формат доставки.

| Изменение | Детали |
|---|---|
| **Двухуровневый пост-фильтр тем** | Keyword-фильтр по списку запрещённых слов (Пентагон, армия, IPO, M&A и др.) + LLM-проверка через gpt-4.1-mini. Применяется после дедупликации, до Enrichment Layer. |
| **Автозапуск bot_subscribe.py** | `collect_and_send.py` при каждом старте проверяет, запущен ли бот подписок, и запускает его в фоне через `ensure_bot_running()`. |
| **HTML-дайджест** | Генерация красивого HTML-файла: светлая тема, карточки новостей, цветные бейджи категорий, блок бизнес-инсайта, блок трендов. Отправка через `sendDocument` Telegram Bot API. |
| **Отказ от текстовой сводки** | Подписчики получают ТОЛЬКО HTML-файл (без дублирующего текстового сообщения). |

**Файлы:** `scripts/collect_and_send.py`, `SKILL.md`

## v3 — 2026-02 (ранее)

**Мотивация:** Между выпусками повторялись темы, которые LLM не отсеивала, потому что не знала контекст предыдущей сводки.

| Изменение | Детали |
|---|---|
| **Enrichment Layer** | Добавлен полный слой обогащения: `calculate_scores` (freshness, mention, authority, business_impact), `enrich_with_llm` (batch-запрос: категория, аудитория, бизнес-инсайт), `detect_trends` (выявление 2–3 трендов). |
| **Уровень 4 дедупликации (LLM-контекст)** | В промпт LLM передаётся список заголовков предыдущей сводки (`previous_digest_titles`). LLM явно получает инструкцию не повторять темы. |
| **Сохранение истории сводок** | После успешной отправки в `sent_news_history.json` сохраняются `previous_digest_titles` для следующего запуска. |
| **Scoring-сортировка** | Перед передачей в LLM новости сортируются по score; в LLM уходит только TOP-20. |

**Файлы:** `scripts/collect_and_send.py`, `data/sent_news_history.json`

## v2 — 2026-01 (ранее)

**Мотивация:** Одни и те же новости появлялись в разных выпусках (повторы между днями). Нужна была персистентная история.

| Изменение | Детали |
|---|---|
| **Многоуровневая дедупликация (L1–L3)** | L1: SHA-256 хэш (title+link). L2: Fuzzy-matching заголовков (SequenceMatcher ≥ 0.65). L3: Jaccard similarity ключевых слов (≥ 0.50). |
| **Персистентная история** | Файл `data/sent_news_history.json` хранит `sent_hashes` и `sent_titles` между запусками. |
| **Система подписок** | Добавлен `bot_subscribe.py` — Telegram-бот для управления подписками. Команды `/start`, `/stop`, `/status`. Данные в `data/subscribers.json`. |
| **Рассылка подписчикам** | Вместо отправки на один chat_id — рассылка всем активным подписчикам из `subscribers.json`. |

**Файлы:** `scripts/collect_and_send.py`, `scripts/bot_subscribe.py`, `data/sent_news_history.json`, `data/subscribers.json`

## v1 — 2025-12 (первая версия)

**Мотивация:** Автоматизировать ежедневный мониторинг AI-новостей и доставку в Telegram.

| Изменение | Детали |
|---|---|
| **Сбор RSS** | Парсинг RSS-лент AI-изданий: AI News, The Decoder, VentureBeat AI, TechCrunch AI, MIT Tech Review, Google AI Blog, OpenAI Blog и др. Окно — последние 24 часа. |
| **LLM-обработка** | Отбор 10 новостей через gpt-4.1-mini: фейк-чек, исключение нерелевантных тем, перевод на русский, форматирование. |

**Файлы:** `scripts/collect_and_send.py`

## Траектория развития

```
v1  Базовый RSS → LLM → Telegram (один получатель)
 ↓
v2  + Персистентная история дедупликации (L1–L3) + Система подписок
 ↓
v3  + Enrichment Layer (scoring, инсайты, тренды) + LLM-контекст (L4)
 ↓
v4  + Пост-фильтр тем (keyword + LLM) + HTML-дайджест + Автозапуск бота
 ↓
v5  + Усиленная дедупликация внутри пачки (3 критерия) + Послабляющий критерий
    + История запусков (run_history.jsonl)
```

**Ключевой вектор:** от простого агрегатора к интеллектуальному редактору с памятью, фильтрами качества и адаптивным поведением.
