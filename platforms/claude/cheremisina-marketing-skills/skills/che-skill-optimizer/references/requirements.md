# Семь групп требований

Это рабочая группировка требований и рекомендаций; Anthropic не называет её
официальным списком из семи пунктов. Дата проверки: 2026-10-07.

| № | Проверка | Уровень и доказательство |
|---|---|---|
| 1 | Краткий основной файл; справка по необходимости | Рекомендация: тело SKILL.md менее 500 строк. Измерить основной текст отдельно от ресурсов. |
| 2 | Корректный YAML; name до 64 символов, lowercase kebab, без XML/reserved words; description непустое до 1024 символов | Требования frontmatter; парсить настоящим YAML-парсером, многострочное описание допустимо. Проверить что делает/когда и третье лицо вручную. |
| 3 | Прямые ссылки из SKILL.md; существующие относительные ресурсы; TOC для references более 100 строк | Рекомендации навигации. Не требовать один уровень вложенности файловой системы: речь о переходах чтения. |
| 4 | Исполнимые скрипты, явные зависимости и ошибки | Проверить произвольную cwd, отсутствующий вход/зависимость. Не выполнять чужие скрипты при статическом аудите. |
| 5 | MCP-инструменты определены реально доступной средой | Проверить server:tool где поддерживается; сообщать недоступность. MCP не обязателен для навыка, которому он не нужен. |
| 6 | Соразмерный workflow и цикл обратной связи | Проверить вход, последовательность, критерий результата; степень свободы соответствует риску. Не превращать рекомендации в лишний шаблон. |
| 7 | Оценка поведения до оптимизации и после | Обычный сценарий, близкий нерелевантный, отсутствующие данные/инструмент. Запуски каждой модели/платформы отдельны от статических проверок. |

## Приватность, лицензия и авторство

Дополнительно проверять все текстовые ресурсы, архивы, имена файлов и метаданные.
Автоматические шаблоны ловят лишь часть секретов/персональных путей: необходим
ручной просмотр клиента/бренда/аккаунтов. Сохранять лицензии сторонних авторов.
Не переносить личную атрибуцию методолога в оригинальное авторство vendor-пакетов.

## Официальные источники

- [Anthropic: Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices)
- [Agent Skills specification](https://agentskills.io/specification)

Имя папки должно совпадать с frontmatter name по Agent Skills. Видимое CHE_имя
хранится отдельно от переносимого lowercase kebab идентификатора. Claude-переменные
и названия MCP конкретной платформы держать в адаптере, не в общей методологии.
