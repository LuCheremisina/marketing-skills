## Пример визуального профиля — только при его выборе

| Правило | Почему важно |
|---|---|
| Только белый фон | Стиль «от руки на бумаге» — основа узнаваемости |
| Красный — единственный цвет | Любой другой цвет разрушает целостность стиля |
| Жирный заголовок, меньший подзаголовок | Иерархия читается с первого взгляда |
| Иллюстрация = метафора, а не буквальность | Обложка должна заинтриговать, а не пересказать |
| Схемы и стрелки от руки | Динамика и «живость» — отличительная черта блога |
| Горизонтальный формат 1400×900 | Пример размера; использовать требования текущего проекта |

**В этом выбранном примере исключены:**
- Фотореалистичные стили
- Тёмный фон
- Синий, зелёный, жёлтый или другие цвета
- Абстрактные узоры без смысловой нагрузки
- Стоковые иконки / flat design
