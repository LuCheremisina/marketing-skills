## 8. Проверить бизнес-смысл

Перед рекомендацией проверить:

1. Кластер присутствует в подтверждённом реестре или прошёл формальный review.
2. Спрос соответствует аудитории и задаче клиента.
3. Всплеск не вызван новостью, омонимом, ботами или единичным событием.
4. Существующую страницу нельзя разумно усилить вместо создания новой.
5. Направление подтверждается связанными запросами и, если доступны, Вебмастером, Метрикой, CRM или продажами.

Для Вебмастера подготовить явное соответствие `query → cluster_id → URL`, затем объединить данные:

```bash
python3 scripts/merge_webmaster_visibility.py trend-report.json webmaster-export.json --json visibility-report.json
```

Не подменять Wordstat метриками видимости. Использовать только следующие выводы: `market_rising_no_page`, `optimize_visibility`, `improve_ctr`, `review_offer`.

Google Trends использовать только как дополнительную относительную проверку. Wordstat остаётся основной измерительной системой.
