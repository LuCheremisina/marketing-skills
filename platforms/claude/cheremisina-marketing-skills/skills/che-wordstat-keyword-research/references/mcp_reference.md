# Wordstat MCP — Справочник параметров

## wordstat.top_requests.read

Возвращает топ похожих запросов + базовую частотность фразы за последние 30 дней.

```
phrase    — строка запроса (обязательно)
regions   — массив GeoID (необязательно; без параметра = вся Россия)
devices   — "all" | "desktop" | "phone" | "tablet" (по умолчанию: ["all"])
limit     — кол-во результатов (1–2000, по умолчанию: 50)
```

Частотность самой фразы — первый элемент результата.

## wordstat.dynamics.read

Тренд частотности по времени.

```
phrase     — строка запроса (обязательно)
period     — "daily" (60 дней) | "weekly" | "monthly" (с 2018 года)
fromDate   — дата начала YYYY-MM-DD (обязательно)
toDate     — дата конца YYYY-MM-DD (необязательно)
regions    — массив GeoID
devices    — "all" | "desktop" | "phone" | "tablet"
```

## wordstat.region_distribution.read

Распределение спроса по регионам за последние 30 дней. Расходует квоту.

```
phrase      — строка запроса (обязательно)
regionType  — "all" | "regions" | "cities" (по умолчанию: "all")
limit       — кол-во регионов (1–1000, по умолчанию: 50)
devices     — "all" | "desktop" | "phone" | "tablet"
```

## wordstat.regions.read

Список всех регионов Яндекса с ID. Не расходует квоту.

```
search — фильтр по названию (необязательно, без учёта регистра)
```

## Полезные GeoID

| GeoID | Регион |
|-------|--------|
| 225 | Россия |
| 213 | Москва |
| 2 | Санкт-Петербург |
| 54 | Екатеринбург |
| 43 | Казань |
| 65 | Новосибирск |
| 11316 | Кемеровская область |

Для других регионов использовать `wordstat.regions.read(search="название")`.
