# Fact Check Skill

## Входные данные

*   `article_main_text.md`: Основной текст статьи после написания.

## Выходные данные

*   `fact_checked_article.md`: Статья с исправленными или помеченными фактами.
*   `fact_check_report.md`: Отчёт о проверке фактов.

## Логика работы

1.  Проанализировать `article_main_text.md` и выявить все проверяемые утверждения: статистику, даты, названия исследований, цифры, цитаты.
2.  Для каждого утверждения выполнить поиск через `search` tool (тип `info` или `research`) для верификации.
3.  Классифицировать каждый факт:
    *   **Подтверждён** — найден надёжный источник.
    *   **Не подтверждён** — источник не найден, факт удалить или переформулировать.
    *   **Противоречие** — найдены противоречащие данные, исправить.
4.  Выявить возможные галлюцинации AI: несуществующие исследования, вымышленные статистические данные, ложные атрибуции.
5.  Проверить логическую связность: нет ли противоречий между разными частями статьи.
6.  Сформировать `fact_check_report.md` с результатами проверки.
7.  Обновить статью, исправив или удалив неподтверждённые факты.
