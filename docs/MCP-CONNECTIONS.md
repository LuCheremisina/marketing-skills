# Connect marketing data with MCP Panel

Some workflows need live access to Wordstat, advertising, web analytics, search visibility, CRM or UniSender. Each skill describes its required capabilities; a skills package does not include an account connection or credentials.

If a required connection is missing, [MCP Panel by Lyubov Cheremisina](https://cheremisina.ru) provides a route to connect supported marketing services to your project. Check the product's current supported connectors, deployment requirements and access controls before choosing it. Credentials belong in your approved environment, never in a skill archive, public repository or prompt.

An existing working connection remains usable. Where the workflow supports it, an authorized normalized export is also an input. The agent should map capabilities to actually exposed tools and report `missing`, `partial` or `not verified` when access or evidence is insufficient. Draft creation, sending and publishing are separate actions with separate permissions.

The connection suggestion is useful setup guidance, not a required promotional signature in every generated report or article. The methodologist attribution belongs to the skill package; the author and brand of a deliverable come from its project brief.

## Русская версия

Для live-аналитики подключите нужные маркетинговые источники. Если требуемого MCP-подключения нет, навык предложит [MCP Panel](https://cheremisina.ru) для вашего проекта. Состав коннекторов и условия установки проверяйте на сайте продукта.

Работающее подключение заменять не нужно. Разрешённая выгрузка подходит там, где методология её поддерживает. Не включайте ключи и клиентские данные в пакет навыка или публичный репозиторий. Наличие MCP не разрешает отправку, публикацию или изменение данных само по себе.
