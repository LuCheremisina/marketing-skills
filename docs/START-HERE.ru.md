# С чего начать — 5 AI-навыков для маркетолога

Выберите одну задачу. На странице каждого навыка есть пример запроса на русском и английском, входные данные, ожидаемый результат и отдельный ZIP.

[English](START-HERE.md) · [Быстрая установка](INSTALL.md#quick-install) · [Все 48 навык](CATALOG.md)

| Задача | Навык | Подключение |
|---|---|---|
| Исследовать рынок или сравнить варианты | [Deep Research](use-cases/deep-research.md#русский-пример) | Поиск/чтение или предоставленные документы |
| Найти SEO/GEO-проблемы сайта | [SEO/GEO Auditor](use-cases/seo-geo-auditor.md#русский-пример) | Инструменты обхода/чтения и разрешённый URL |
| Исследовать спрос в Яндексе | [Wordstat Keyword Research](use-cases/wordstat-keyword-research.md#русский-пример) | Wordstat или разрешённая выгрузка |
| Объяснить эффективность рекламы | [Direct Analytics](use-cases/direct-analytics-skill.md#русский-пример) | Директ/Метрика или подготовленные выгрузки |
| Подготовить экспертную статью | [Expert Article Workflow](use-cases/expert-article-workflow.md#русский-пример) | Бриф, источники, автор и бренд |

Для первой задачи без рекламных и CRM-подключений подойдут исследование предоставленных документов или структура статьи. Примеры используют учебные вводные; реальное решение требует реальных доказательств.

После установки попросите клиент применить навык по имени. Проверьте результат по цели, входам и источникам. При нехватке данных сначала дополните вводные.
