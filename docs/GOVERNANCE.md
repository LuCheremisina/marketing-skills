# Versions, privacy and updates

The public accepted release is the client distribution source. Private development and local modifications remain private until explicitly sanitized, tested and reviewed. No private Git history is copied into this repository.

Compare a last installed baseline, local bytes and upstream source. Use declared version plus source commit, file hashes, changelog and behavior. A file modification date cannot decide precedence. Unversioned upstream content is pinned by commit; adapter version is separate from original version. License or immutable-version conflicts require review.

Monthly checks: first day at 00:00 Asia/Novosibirsk. GitHub schedule evaluates the correct previous-month UTC boundary and checks the calendar date; delayed delivery and failures are reported. A local Codex follow-up inventories local skills and prepares private reconciliation separately. Manual source verification runs before release/installation. Between checks a new upstream version can remain undetected.

The workflow is designed to prepare a PR and never merges, publishes or installs. A live six-source no-change run passed on 2026-10-06; automatic PR creation is not yet verified and depends on repository workflow permissions. Changed license, diverged local adaptation, missing source or failed tests block automated replacement. Provider-managed skills use provider update mechanisms; never downgrade an installed plugin to an older public mirror.

Public content excludes client profiles, actual account/contact identifiers, credentials, closed datasets, transcripts, developer home paths, private source URLs and local inventory logs. Explicitly permitted public credits are methodologist name, both websites and the public skill repository. Synthetic examples are not measured results.

Compatibility statuses: `verified`, `requires_connection`, `not_verified`, `not_supported`. Record actual application/model version, tested task, resource loading and evidence. Structural validation is separate from behavioral tests, publication, live usage and measured business impact.
