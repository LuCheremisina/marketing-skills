For a first task without advertising or CRM connections, start with a document-based research question or article outline. The examples use synthetic inputs; real decisions need real evidence.

After installation, ask your client to use the skill by name. Check the output against the stated task and source requirements. If an input is missing, supply it before expecting the full result.
