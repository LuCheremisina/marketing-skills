# Установка всех маркетинговых навыков или одного навыка

[English](INSTALL.md) · [Полный плагин по системам](INSTALL-PLUGIN.ru.md)

## Быстрая установка

CLI [skills](https://github.com/vercel-labs/skills) требует **Node.js 22.20+ и Git**. Он устанавливает папки Agent Skills. Для регистрации полного плагина в Codex, Claude Code, Claude / Cowork или ChatGPT используйте [отдельную инструкцию](INSTALL-PLUGIN.ru.md).

### Все 34 авторских навыка

Выполните команду для своей системы:

```sh
# Codex
npx skills add LuCheremisina/marketing-skills --skill '*' -a codex -g -y
# Claude Code
npx skills add LuCheremisina/marketing-skills --skill '*' -a claude-code -g -y
# Cursor
npx skills add LuCheremisina/marketing-skills --skill '*' -a cursor -g -y
```

| Параметр | Значение |
|---|---|
| `--skill '*'` | Все обнаруженные навыки; кавычки защищают от подстановки имён файлов |
| `-a codex` / `claude-code` / `cursor` | Система, для которой устанавливаются навыки |
| `-g` | Для пользователя во всех проектах |
| `-y` | Без интерактивных вопросов |

Для одного проекта уберите `-g` и запустите из его папки. Для ручного выбора навыков и систем: `npx skills add LuCheremisina/marketing-skills`. Флаг `--all` выбирает также всех агентов; для одной системы используйте `--skill '*' -a …`.

### Один навык

```sh
npx skills add LuCheremisina/marketing-skills --skill che-deep-research
```

По умолчанию — в текущий проект; выберите систему, если появится вопрос. Для глобальной установки, например в Cursor, добавьте `-a cursor -g`. [Пять навыков для старта](START-HERE.ru.md) содержат отдельные команды, ZIP и примеры.

### Посмотреть состав до установки

```sh
# 34 авторских маркетинговых навыка
npx skills add LuCheremisina/marketing-skills --list
# Включить поиск вложенных сторонних инженерных пакетов
npx skills add LuCheremisina/marketing-skills --list --full-depth
```

14 сторонних инженерных навыков необязательны. Сначала изучите список и лицензии, затем выберите нужные. Нативный авторский плагин содержит 34 навыка; vendor ZIP устанавливается отдельно.

Быстрая установка получает текущие исходники репозитория. Она не проверяет manifest фиксированного выпуска и не подключает внешние аккаунты. CLI имеет собственную телеметрию; для отключения задайте `DISABLE_TELEMETRY=1` (PowerShell: `$env:DISABLE_TELEMETRY='1'`) перед запуском. [Документация CLI](https://github.com/vercel-labs/skills/blob/main/docs/commands.md).

## Использование и проверка

Начните новый чат или сеанс и попросите:

```text
Примени che-deep-research. Подготовь исследовательский бриф
для вымышленного B2B-сервиса. Сначала уточни недостающие вводные.
```

В Codex после CLI-установки можно выбрать `$che-deep-research`. В Claude Code после установки нативного плагина — `/marketing-skills:che-deep-research`; пространство имён плагина не относится к отдельным CLI-папкам. В Cursor и других клиентах выберите навык через интерфейс или назовите его в запросе. [Подробные примеры](../README.ru.md#как-пользоваться).

Проверьте `npx skills list -g` (для проекта — без `-g`), наличие ожидаемых навыков, чтение одного справочного файла и пробную задачу. Зависимости Python, инструменты и API/MCP нужны отдельно. Установка на компьютере не переносится автоматически в отдельную облачную среду.

## Обновление и удаление

Для навыков, установленных через CLI:

```sh
npx skills check
npx skills update che-deep-research -g
npx skills remove che-deep-research -g
```

Вторая строка обновляет один глобальный навык, третья — удаляет его. Для обновления всех глобальных CLI-навыков, включая другие источники, используйте `npx skills update -g`. Для проекта — `npx skills update -p`, удаление без `-g` из папки проекта. Сохраните собственные правки перед заменой.

Нативные плагины обновляются через [управление Plugins](INSTALL-PLUGIN.ru.md#обновление-и-удаление), а не `npx`. Не включайте одновременно плагин и CLI-копию того же набора.

## ZIP и установка плагина

Для всех 34 маркетинговых навыков одним плагином: [русская инструкция](INSTALL-PLUGIN.ru.md). В [Releases](https://github.com/LuCheremisina/marketing-skills/releases/latest) доступны отдельные ZIP навыков и два плагина: авторский `marketing-skills-plugin-<version>.zip` (34 навыка) и необязательный `marketing-skills-vendor-<version>.zip` (14 сторонних).

Для кодовых клиентов распакуйте полную папку навыка в поддерживаемую клиентом папку Skills, сохранив `SKILL.md` и все ресурсы. Для Claude / Cowork и ChatGPT используйте поддерживаемый импорт навыка или плагина. Обычное прикрепление ZIP к чату не является установкой. Полный архив исходников репозитория предназначен для просмотра и инструментов, а не нативного импорта плагина.

## Проверяемая установка

Для фиксированной версии, проверки SHA-256, контролируемой замены и отката используйте установщик репозитория. Выберите выпуск, проверьте `manifest.json` и `SHA256SUMS`, изучите изменения.

Из папки инструментов этого репозитория:

```sh
python3 scripts/install.py --manifest /absolute/release/manifest.json --target-dir /absolute/skill-root --ids che-daily-ai-news-digest,che-expert-article-workflow
```

Это **предпросмотр**, без применения. Обязательны явные `--target-dir` и `--ids`. Укажите папку, которую использует клиент; не заменяйте управляемый кеш плагинов. Добавьте `--apply` после проверки плана и расположения резервной копии. Храните копии вне папок обнаружения навыков. Установщик не перезаписывает изменённые копии без подтверждённой базы или отдельной проверки каждого навыка.

Сохраните журнал транзакции; для отката используйте режим `--rollback JOURNAL`. Изменённая после установки папка не должна уничтожаться откатом. Затем обновите список навыков в клиенте, проверьте обнаружение и безопасную задачу. Для переименованных навыков есть [карта миграции](MIGRATION-2.0.md). Профили клиентов и ключи храните вне пакетов.

## Grok Bot

Сохраните выбранную методику в приватной библиотеке навыков через поддерживаемый интерфейс Bot. Перенесите правила решений, формат результата и необходимые ресурсы. Проверьте чтение файлов, выполнение скриптов и поведение при нехватке данных. Если ресурс не переносится или скрипт недоступен, укажите ограничение; текстовая инструкция не подтверждает полную установку пакета. Универсальная команда импорта всего плагина в Grok Bot не подтверждена. Установка навыка не создаёт рутину.
