# Knowledge Graph Builder Skill

## Входные данные

*   `eeat_article.md`: Статья, усиленная по E-E-A-T.

## Выходные данные

*   `kg_article.md`: Статья с интегрированными данными графа знаний.
*   `knowledge_graph.json`: JSON-файл с Entity Graph.

## Логика работы

1.  Проанализировать статью и извлечь сущности:
    *   Бренды
    *   Материалы
    *   Технологии
    *   Компании
    *   Люди
    *   Термины
2.  Для каждой сущности определить атрибуты и связи с другими сущностями.
3.  Сформировать Entity Graph в формате JSON.
4.  При необходимости добавить в статью структурированные данные, усиливающие связи между сущностями (например, определения терминов в контексте).
