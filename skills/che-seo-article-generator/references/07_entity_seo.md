# Entity SEO

## Входные данные

- `fact_checked_article.md`
- entity keywords из Semantic Skill
- `inputs/brand_voice.txt` (бренд, автор, ключевые понятия)

## Выходные данные

- `entity_seo_article.md`

## Логика работы

1. Прочитать `inputs/brand_voice.txt` — выявить ключевые сущности бренда (автор, компания, специализация).
2. На основе статьи и brand_voice определить релевантные сущности: бренды, технологии, персоналии, термины.
3. Обеспечить достаточное упоминание сущностей через синонимы и связанные термины — без переоптимизации.
4. Убедиться, что упоминания органично вписаны в контекст.
