# Cover Generation Prompt

## Prompt Template

Create an editorial cover illustration in the style of an intellectual sketch for a blog article.

Style: strategic sketch, business editorial sketch, hand-drawn analytical illustration, clean minimalist layout.

The image should look like an author's visual note: thin sketch lines, logical arrows, analytical blocks, diagrams, structure, a sense of clarity and systematic approach.

Clean, modern composition with plenty of white space.

Color palette (default — replace with brand palette from inputs/config.txt if specified):
- Primary accent: `#cf391b` (terracotta red)
- Secondary: `#666666` (graphite gray)
- Main graphics: `#222222` (near-black)
- Background: `#ffffff` (white)

Image format: 16:9.

**Safe zone rule:** All meaningful visual content MUST be placed within the central 360×230px safe zone. Areas outside should remain clean and free of important content. Do NOT draw the safe zone frame — it is invisible.

**Topic-specific addition:** [Add a brief description of the article topic to contextualize sketch elements.]

## Negative Prompt

no stock photo, no realistic corporate people, no handshake, no neon colors, no glossy 3d, no childish illustration, no chaotic composition, no bright gradients, no canva template style, no visual clutter, no random icons
