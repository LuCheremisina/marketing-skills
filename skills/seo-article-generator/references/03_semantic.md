# Semantic Skill

## Входные данные

*   `wordstat_results`: Результаты `wordstat-keyword-research` (Markdown-таблица).

## Выходные данные

*   `focus_keyword`: Основное ключевое слово.
*   `secondary_keywords`: Второстепенные ключевые слова.
*   `entity_keywords`: Ключевые слова-сущности.
*   `search_queries`: Поисковые вопросы.

## Лимиты семантического ядра

| Параметр | Значение |
|---|---|
| Минимальная частотность ключа | ≥ 100 показов/мес |
| Focus keyword | 1 ключ |
| Secondary keywords | 5–8 ключей |
| Entity keywords | 3–5 ключей |
| Search queries | 3–5 вопросов |

## Логика работы

1.  Проанализировать `wordstat_results`.
2.  Отфильтровать все ключи с частотностью **менее 100 показов/мес** — они не используются.
3.  Из оставшихся ключей выбрать focus keyword с наибольшим объёмом поиска (1 ключ).
4.  Определить secondary keywords (5–8 ключей с учётом частотности и релевантности теме).
5.  Определить entity keywords (3–5 ключей-сущностей: бренды, технологии, персоналии).
6.  Определить search queries (3–5 вопросов в формате «как...», «почему...», «что такое...»).
7.  Сохранить данные для передачи в следующие этапы.
