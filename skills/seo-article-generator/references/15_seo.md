# SEO Skill

## Входные данные

*   `article_with_cta.md`: Статья с CTA.
*   Данные из `Semantic Skill`: focus keyword, secondary keywords, таблица семантического ядра (с данными Wordstat).
*   `inputs/seo_requirements.txt`: SEO-требования (папка `inputs/` в корне проекта).

## Выходные данные

*   `seo_metadata.md`: SEO-метаданные в формате Markdown (H1, Title, Meta Description, Анонс, семантическое ядро, ключевые слова списком, slug, теги).

## Логика работы

1.  Сгенерировать:
    *   **H1:** Основной заголовок, включает focus keyword.
    *   **SEO Title:** 50–60 символов, включает focus keyword (по Yoast).
    *   **Meta Description:** 150–160 символов, включает focus keyword и призыв к действию.
    *   **Анонс (превью блога):** 1–2 предложения, ~60–80 символов — короткий анонс для поля превью/анонса на странице блога. Это НЕ Meta Description: анонс короче и менее формальный, подходит для карточки поста в блоге.
    *   **Focus Keyword:** Основное ключевое слово.
    *   **Keywords (таблица):** Полная таблица семантического ядра с данными Wordstat — переносится из результатов Semantic Skill. Содержит: ключевую фразу, частотность, тип (ВЧ/СЧ/МЧ), статус, рекомендацию по размещению.
    *   **Keywords (список):** Все валидные ключи через запятую — отдельный блок сразу после таблицы для быстрого копирования (например, в поле Keywords CMS).
    *   **Slug:** URL-slug статьи — только хвост (латиницей, через дефисы). Без префикса `/blog/tpost/` и без доменного имени. Пример: `pochemu-marketing-ne-rabotaet`.
    *   **Tags:** Теги статьи (3–5 штук).
2.  **Валидация:** Focus keyword включён в Title, Description, H1 и первый абзац статьи.
3.  Сохранить в `seo_metadata.md` в формате Markdown. НЕ сохранять как .json — формат строго Markdown.
4.  H1 не вставлять в текст статьи — он передаётся отдельно через метаданные.

## Формат seo_metadata.md

# SEO Metadata

**H1:** Заголовок статьи с focus keyword

**SEO Title:** 50–60 символов с focus keyword

**Meta Description:** 150–160 символов с focus keyword и CTA

**Анонс (превью блога):** 1–2 предложения, ~60–80 символов

**Focus Keyword:** основное ключевое слово
