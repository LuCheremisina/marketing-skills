# Полный чек-лист SEO и GEO аудита (Версия 2026)

Этот чек-лист представляет собой исчерпывающее руководство по аудиту веб-сайтов, объединяющее классические требования поисковых систем (Google, Яндекс) и новые стандарты Generative Engine Optimization (GEO) для AI-поисковиков (ChatGPT, Perplexity, Google AI Overviews, Claude).

## 1. Техническое SEO (Technical SEO)

### 1.1. Индексация и сканирование (Критический приоритет)
- [ ] **robots.txt**: Файл существует, корректно настроен и не блокирует важные разделы сайта.
- [ ] **Доступ AI-ботов**: В `robots.txt` разрешен доступ для `GPTBot`, `PerplexityBot`, `ClaudeBot`, `OAI-SearchBot`, `Google-Extended` (если стратегия подразумевает присутствие в AI-ответах).
- [ ] **XML Sitemap**: Карта сайта доступна по стандартному адресу (или указана в robots.txt), содержит только канонические страницы с кодом 200 OK.
- [ ] **Meta Robots**: Отсутствуют ошибочные теги `noindex`, `nofollow` на целевых страницах.
- [ ] **Канонические URL (Canonical)**: Тег `rel="canonical"` присутствует на всех страницах и указывает на правильную версию, предотвращая дублирование контента.
- [ ] **Hreflang**: Для мультиязычных сайтов корректно настроены атрибуты `hreflang`, включая `x-default`.
- [ ] **HTTP-заголовки**: Проверка заголовка `X-Robots-Tag` на предмет скрытых запретов индексации.

### 1.2. Производительность и Core Web Vitals (Высокий приоритет)
- [ ] **LCP (Largest Contentful Paint)**: Время отрисовки самого крупного элемента менее 2.5 секунд.
- [ ] **INP (Interaction to Next Paint)**: Задержка реакции на действия пользователя менее 200 мс.
- [ ] **CLS (Cumulative Layout Shift)**: Смещение макета менее 0.1.
- [ ] **Скорость загрузки (TTFB)**: Время ответа сервера (Time to First Byte) менее 600 мс.
- [ ] **Оптимизация изображений**: Использование современных форматов (WebP, AVIF), наличие атрибутов `width` и `height`, настроенный lazy loading.
- [ ] **Минификация**: CSS, JavaScript и HTML файлы минифицированы.

### 1.3. Безопасность и архитектура (Высокий приоритет)
- [ ] **HTTPS**: Сайт работает по защищенному протоколу, SSL-сертификат действителен.
- [ ] **Редиректы**: Отсутствуют цепочки редиректов (более 2 шагов) и циклические редиректы. Использование 301 редиректа вместо 302 для постоянных перенаправлений.
- [ ] **Зеркала сайта**: Настроены редиректы с www на non-www (или наоборот) и с http на https.
- [ ] **Мобильная адаптивность**: Наличие тега `viewport`, корректное отображение на мобильных устройствах, достаточный размер кликабельных элементов (tap targets).
- [ ] **Структура URL**: URL-адреса человекопонятные (ЧПУ), короткие, содержат ключевые слова, без лишних параметров.

## 2. Внутренняя оптимизация (On-Page SEO)

### 2.1. Мета-теги и заголовки (Высокий приоритет)
- [ ] **Title**: Уникальный для каждой страницы, длина 50-60 символов, содержит главное ключевое слово ближе к началу.
- [ ] **Meta Description**: Уникальное описание, длина 150-160 символов, содержит призыв к действию (CTA) и ключевые слова.
- [ ] **Заголовок H1**: На странице присутствует только один тег H1, он уникален и отражает суть контента.
- [ ] **Иерархия заголовков (H2-H6)**: Логичная структура без пропусков уровней (например, H3 не идет сразу после H1).
- [ ] **Open Graph и Twitter Cards**: Настроены мета-теги для корректного отображения превью при шеринге в социальных сетях и мессенджерах.

### 2.2. Контент и медиа (Средний приоритет)
- [ ] **Атрибуты Alt**: Все значимые изображения имеют осмысленный альтернативный текст.
- [ ] **Уникальность контента**: Отсутствие полных дублей внутри сайта (проблема каннибализации) и плагиата с других ресурсов.
- [ ] **Объем и глубина**: Контент полностью раскрывает интент пользователя (search intent), нет "тонких" страниц (thin content).
- [ ] **Внутренняя перелинковка**: Наличие контекстных ссылок на другие релевантные страницы сайта.
- [ ] **Битые ссылки**: Отсутствие ссылок, ведущих на страницы с ошибкой 404.

## 3. Generative Engine Optimization (GEO) и AI-поиск

### 3.1. Структурированные данные (Критический приоритет для GEO)
- [ ] **Формат JSON-LD**: Разметка внедрена в предпочтительном формате JSON-LD.
- [ ] **Базовая разметка**: Присутствует `Organization` или `LocalBusiness` с полными данными (NAP, логотип, соцсети).
- [ ] **Разметка контента**: Использование `Article`, `NewsArticle` или `BlogPosting` для информационных материалов.
- [ ] **FAQPage**: Необязательная разметка видимых вопросов и ответов. Google прекратил FAQ rich results с 7 мая 2026 года; отсутствие не является штрафом, наличие не гарантирует AI-цитирование.
- [ ] **Product / Review**: Для e-commerce обязательна разметка товаров, цен, наличия и отзывов с рейтингом.
- [ ] **BreadcrumbList**: Разметка "хлебных крошек" для понимания структуры сайта нейросетями.

### 3.2. Оптимизация контента для LLM (Высокий приоритет)
- [ ] **Файл llms.txt**: При наличии проверить содержание. Необязательный экспериментальный файл; не требование Google и не основание для штрафа за отсутствие.
- [ ] **TL;DR и Резюме**: Наличие кратких выжимок (Key Takeaways) в начале длинных статей.
- [ ] **Прямые ответы**: Контент содержит четкие, лаконичные ответы на вопросы "Что это?", "Как сделать?", "Сколько стоит?".
- [ ] **Цитируемость**: Наличие уникальной статистики, авторских исследований, оригинальных графиков или четких определений, которые AI захочет процитировать.
- [ ] **Свежесть данных**: Указание даты публикации и даты последнего обновления (`Last updated`). AI отдает приоритет свежей информации.

### 3.3. Сигналы E-E-A-T (Опыт, Экспертность, Авторитетность, Достоверность)
- [ ] **Страница "О нас"**: Подробная информация о компании, ее миссии, истории и команде.
- [ ] **Профили авторов**: Наличие страниц авторов с их биографией, регалиями, ссылками на соцсети (LinkedIn) и списком публикаций.
- [ ] **Внешние ссылки**: Ссылки на авторитетные источники (исследования, официальные сайты, .edu, .gov) для подтверждения фактов.
- [ ] **Политика прозрачности**: Наличие страниц "Политика конфиденциальности", "Условия использования", "Контакты".

## 4. Внешнее SEO и Локальное продвижение (Off-Page & Local)

### 4.1. Упоминания бренда и отзывы (Высокий приоритет для GEO)
- [ ] **Unlinked Mentions**: Мониторинг упоминаний бренда без ссылок на авторитетных площадках (Reddit, Quora, профильные форумы). AI использует их для оценки авторитета.
- [ ] **Тональность (Sentiment)**: Преобладание позитивных или нейтральных отзывов на внешних площадках.
- [ ] **Работа с отзывами**: Регулярные ответы на отзывы клиентов (как положительные, так и отрицательные).

### 4.2. Локальное SEO
- [ ] **Google Business Profile**: Профиль заполнен на 100%, данные актуальны, есть свежие фото и публикации.
- [ ] **Яндекс.Бизнес**: Профиль верифицирован, информация совпадает с данными на сайте.
- [ ] **NAP Consistency**: Единообразие названия, адреса и телефона (Name, Address, Phone) во всех локальных каталогах (2GIS, Zoon, Yelp).

## 5. Специфика по типам страниц

### 5.1. Лендинги (Landing Pages)
- [ ] Четкое ценностное предложение (UVP) в первом экране (H1).
- [ ] Заметные и однозначные призывы к действию (CTA).
- [ ] Блоки социального доказательства (Social Proof): логотипы клиентов, кейсы, отзывы.
- [ ] Высокая скорость загрузки мобильной версии.

### 5.2. Интернет-магазины (E-commerce)
- [ ] Удобная структура категорий и фильтрация товаров.
- [ ] Наличие отзывов пользователей на страницах товаров (User-Generated Content).
- [ ] Микроразметка `Product` с указанием цены и статуса `InStock`.
- [ ] Оптимизация страниц пагинации (rel="next/prev" или canonical).

### 5.3. Информационные порталы и Блоги
- [ ] Наличие блока "Содержание" (Table of Contents) с якорными ссылками.
- [ ] FAQ добавлять только при реальных вопросах аудитории; разметка необязательна и не обещает видимость или AI-цитирование.
- [ ] Блоки перелинковки "Читайте также" или "Похожие статьи".
- [ ] Указание времени чтения (Read time) и даты обновления.
