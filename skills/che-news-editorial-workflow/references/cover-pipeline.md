# Обложка

Получить визуальный профиль, размеры и разрешённый провайдер. Сохранить заданную модель; не менять её автоматически. Доступен che-cover-production — использовать его; иначе выполнить те же шаги нативным инструментом. Нет подключения — бриф и явная блокировка генерации. Сохранить мастер, экспортировать производный файл, открыть оба для QA. CoverAlt описывает сцену, а не дублирует title. Отсутствующая обложка блокирует публикацию только если таковы требования целевой площадки; не обходить их без решения владельца.
