# Согласование терминов

Если проект поддерживает глоссарий, проверить основной термин, утверждённое определение, canonical slug и наличие страницы. Новую сущность описать по первоисточнику, без дубликатов. Не создавать раздел глоссария в чужой архитектуре автоматически. Изменения терминов согласовывать с текущим проектным процессом. Отсутствующая страница не становится действующей ссылкой.
