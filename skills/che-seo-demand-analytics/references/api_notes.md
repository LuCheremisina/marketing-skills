# Особенности Яндекс API — заметки для пайплайна

## Wordstat MCP (wordstat.top_requests.read)

- Данные за предыдущий полный календарный месяц (не последние 30 дней)
- `topRequests[0]` — сама исходная фраза с суммарной частотностью
- `regions` — массив GeoID; без параметра = вся Россия
- GeoID региона → `wordstat.regions.read(search="название")`
- `limit` до 2000; для ниши достаточно 100

## Вебмастер MCP (webmaster.queries.read)

API v4 исторически возвращает пустые `indicators {}` — числовые показатели
(показы, клики, позиции) недоступны. MCP может решить это на уровне адаптера —
проверять при каждом запуске.

**Fallback — ручная выгрузка CSV:**
Вебмастер → Эффективность → Статистика запросов → Популярные запросы → CSV
Добавить колонку «Ср. позиция показа» через шестерёнку перед выгрузкой.

Структура CSV: `Query, Impressions, Clicks, CTR, Avg. position`
Русские заголовки: `Запрос, Показы, Клики, CTR, Ср. позиция показа`

## Метрика MCP (web_analytics.report.read)

- Фильтр по URL + поисковым фразам одновременно → `contains_sensitive_data: true` → пустой ответ
- Страницы и фразы собираются раздельно
- Фильтр по домену: `ym:s:startURL=~'myshop.ru'`
- Органический трафик: `ym:s:trafficSource=='organic'`
- `limit=1000` охватывает большинство проектов; увеличить если страниц больше
