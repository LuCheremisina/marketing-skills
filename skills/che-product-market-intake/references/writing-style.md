# Writing style for intake reports

Use this in-skill guide when writing the human-readable intake report.
An optional project-local style file may override these rules if the
customer supplies one; do not assume any file outside this package exists.

- Short paragraphs. Prefer concrete nouns and verbs over abstractions.
- State facts with a source. Label inferences as **Гипотеза**.
- Do not open with filler such as "In today's rapidly evolving landscape".
- Do not invent persona names, photos, or quoted customers.
- Keep industry jargon inside the customer's own words or examples.
- If a field is unknown, write `unknown` or "требует уточнения".
