# Протокол автопродолжения

## Содержание

- Когда использовать
- Обзор стратегии
- Файл состояния продолжения
- Запуск агента продолжения
- Протокол качества агента продолжения
- Загрузка контекста (КРИТИЧНО)
- Чеклист перед генерацией
- Генерация по разделам
- Решение о передаче
- Обязанности финального агента
- Коммуникация с пользователем


## Когда использовать

Запустить автопродолжение, когда отчёт превышает 18 000 слов в одном запуске.

---

## Обзор стратегии

1. Сгенерировать разделы 1–10 (оставаться ниже 18К слов)
2. Сохранить файл состояния продолжения с сохранением контекста
3. Запустить агент продолжения через Task
4. Агент продолжения: читает состояние → генерирует следующую партию → при необходимости запускает следующего
5. Цепочка продолжается рекурсивно до завершения

---

## Запуск агента продолжения

Использовать Task:

```
Task(
  subagent_type="general-purpose",
  description="Продолжение генерации отчёта deep-research",
  prompt="""
ЗАДАЧА ПРОДОЛЖЕНИЯ: Продолжить существующий отчёт deep-research.

КРИТИЧНЫЕ ИНСТРУКЦИИ:
1. Прочитать состояние продолжения: ${RESEARCH_OUTPUT_DIR:-./research_output}/research_output/continuation_state_[report_id].json
2. Прочитать существующий отчёт: [file_path из состояния]
3. Прочитать ПОСЛЕДНИЕ 3 завершённых раздела для стиля/потока
4. Загрузить контекст исследования: темы, нарративная дуга, стиль
5. Загрузить реестр источников из state.artifacts.sources_path — использовать стабильные source_ids,
   присвоить отображаемые номера через citation_manager.py

ЗАДАЧА:
Сгенерировать следующую партию (оставаться ниже 18 000 слов):
[Перечислить next_sections из состояния]

Использовать Write/Edit для добавления в: [file_path]

ГЕЙТЫ КАЧЕСТВА:
- Слов на раздел: В пределах ±20% от avg_words_per_finding
- Плотность ссылок: Соответствовать ±0.5 на 1К слов
- Доля прозы: Поддерживать ≥80%
- Связь с темами: Раздел привязан к key_themes

После генерации:
- Если остались разделы: Обновить состояние, запустить следующего агента
- Если финальные разделы: Сгенерировать библиографию, верифицировать отчёт, удалить файл состояния
"""
)
```

## Протокол качества агента продолжения

### Загрузка контекста (КРИТИЧНО)

1. Прочитать continuation_state.json → загрузить ВСЕ контексты
2. Прочитать файл отчёта → просмотреть последние 3 раздела
3. Извлечь паттерны:
   - Сложность структуры предложений
   - Используемая техническая терминология
   - Паттерны расстановки ссылок
   - Стиль переходов между абзацами

### Чеклист перед генерацией

- [ ] Загружен контекст исследования (темы, вопрос, нарративная дуга)
- [ ] Просмотрены предыдущие разделы для потока
- [ ] Загружен реестр источников (стабильные source_ids, не номера ссылок)
- [ ] Загружены целевые метрики качества (слова, плотность, стиль)
- [ ] Понята нарративная позиция (начало/середина/конец)

### Генерация по разделам

1. Сгенерировать содержимое раздела
2. Проверки качества:
   - Число слов в пределах ±20%
   - Плотность ссылок соответствует
   - Доля прозы ≥80%
   - Связь с темой подтверждена
   - Стиль последовательный
3. Если ЛЮБАЯ не прошла: Перегенерировать
4. Если прошла: Записать в файл, обновить состояние

### Решение о передаче

Рассчитать: Текущие слова + оставшиеся разделы × avg_words_per_section
- Если итого <18К: Сгенерировать всё + завершить
- Если итого >18К: Сгенерировать частично, обновить состояние, запустить следующего агента

### Обязанности финального агента

- Сгенерировать финальные разделы контента
- Сгенерировать ПОЛНУЮ библиографию из state.citations.bibliography_entries
- Прочитать весь собранный отчёт
- Запустить валидацию: `python scripts/validate_report.py --report [путь]`
- Удалить continuation_state.json (очистка)
- Сообщить пользователю о завершении

## Коммуникация с пользователем

После запуска продолжения:
```
Генерация отчёта: Часть 1 завершена (N разделов, X слов)
Автопродолжение через запущенного агента...
   Следующая партия: [список разделов]
   Прогресс: [X%] завершено
```
