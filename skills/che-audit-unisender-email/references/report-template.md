# Шаблон отчёта

## 1. Управленческое резюме

- Статус: `complete` / `partial`.
- Главный вывод.
- Наиболее сильная возможность роста переходов.
- Главное ограничение доказательств.
- Следующий рекомендуемый тест.

## 2. Охват и качество данных

| Показатель | Значение |
|---|---:|
| Дата среза | |
| Окно | D+7 |
| Primary включено | |
| Resend отдельно | |
| Исключено | |
| Link-level complete | |
| UTM complete | |
| CRM complete | |

Перечислить пропуски, несопоставимые кампании и влияние ограничений на выводы.
Не принимать заявленный статус источника без проверяемых строк: карта ссылок должна содержать `links`, а полная UTM-разметка — уникальный `utm_content` каждого размещения.

## 3. Scorecard primary-кампаний

Показать delivery, open rate, CTR, CTOR, отписки, sessions per clicker, engaged rate, lead CR и leads per 1,000 delivered. Сравнить кампании с weighted baseline и медианой.

## 4. Карта ссылок

| Кампания | Размещение | Элемент | All clicks | Unique clickers | Visits | Engaged visits | Leads |
|---|---|---|---:|---:|---:|---:|---:|

Не заполнять неизвестные значения нулями. Отмечать отсутствие unique link clickers.

## 5. Post-click воронка

По каждому `utm_content` показать падение между кликом, визитом, вовлечённым визитом и заявкой. Отдельно назвать элементы с высоким CTR, но слабым качеством трафика, и элементы с небольшим объёмом, но высокой конверсией.

## 6. Resend-анализ

Не смешивать с primary. Показать инкрементальный охват, клики, визиты, заявки, отписки и жалобы. Не называть изменение результатом темы без оговорки о смешивающих факторах.

## 7. Интерпретация

### Факты

Только подтверждённые числа и наблюдения.

### Вероятные драйверы

Объяснения, поддержанные несколькими сопоставимыми наблюдениями.

### Гипотезы

Недоказанные объяснения с указанием, какие данные их проверят.

## 8. Рекомендации для следующего письма

Дать не более трёх приоритетов:

1. изменение;
2. ожидаемый механизм влияния;
3. целевая метрика;
4. guardrail;
5. критерий успеха;
6. окно измерения.

Обязательно приложить точную UTM-разметку всех CTA и один главный тест. Не обещать эффект без достаточных данных.

## 9. План накопления доказательств

Указать, сколько сопоставимых кампаний и событий ещё нужно, какие поля отсутствуют и что автоматизировать в MCP/n8n.
