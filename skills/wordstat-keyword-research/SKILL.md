# Wordstat Keyword Research

Семантический анализ через Яндекс.Wordstat MCP. Токены в пакете не хранятся —
аутентификация настраивается в MCP-сервере заказчика.

## Required external dependencies

- Yandex Wordstat MCP server with tools `wordstat.top_requests.read`,
  `wordstat.dynamics.read`, `wordstat.region_distribution.read`,
  `wordstat.regions.read`.
- Without that MCP, do not invent frequencies; mark them as unverified.

## MCP-инструменты

| Инструмент | Назначение | Квота |
|---|---|---|
| `wordstat.top_requests.read` | Частотность фразы + топ похожих запросов (30 дней) | Расходует |
| `wordstat.dynamics.read` | Тренд по дням / неделям / месяцам | Расходует |
| `wordstat.region_distribution.read` | Распределение спроса по регионам и городам | Расходует |
| `wordstat.regions.read` | Список регионов с ID (поиск по названию) | Бесплатно |

## Workflow

### 1. Определить входные данные

**Если прислан текст статьи** — извлечь 10–15 кандидатов:
- Основная тема (1–2 слова)
- Ключевые сущности: продукты, сервисы, бренды, категории
- Фразы-действия: купить, заказать, сравнить, как выбрать...
- Длинные хвосты из заголовков и подзаголовков (3–5 слов)

**Если прислан список фраз или конкретная тема** — использовать напрямую.

Если фраз больше 15 — обработать батчами по 15, предупредить пользователя.

### 2. Определить регион (если указан)

```
wordstat.regions.read(search="Москва")
```

Без региона — не передавать параметр `regions` (данные по всей России).

### 3. Получить частотность и расширить семантику

Для каждого кандидата:
```
wordstat.top_requests.read(phrase="...", regions=[ID], limit=50)
```

`limit=50` возвращает топ-50 похожих запросов. Из них выбрать 3–5 неожиданных высокочастотных фраз, которых не было в исходном списке — добавить в итоговую таблицу.

**Операторы уточнения (передаются в `phrase`):**

| Оператор | Что делает | Пример |
|---|---|---|
| `"..."` | Только точная фраза, без словоформ | `"купить смартфон"` |
| `!слово` | Фиксированная словоформа | `!купить !телефон` |
| `+слово` | Обязательное слово (стоп-слова) | `смартфон +бу` |
| `-слово` | Исключить слово | `смартфон -чехол` |

### 4. Тренды (если просят или есть признаки сезонности)

```
wordstat.dynamics.read(phrase="...", period="monthly", fromDate="2025-01-01")
```

Использовать для фраз, связанных с сезоном, праздниками, учебным годом — и всегда, если пользователь явно просит.

### 5. Региональное распределение (по запросу)

```
wordstat.region_distribution.read(phrase="...", regionType="regions")
```

Расходует квоту — вызывать только если пользователь спросил про регионы или целевую географию.

### 6. Сформировать итоговую таблицу

| # | Запрос | Частотность/мес | Тип | Рекомендация по размещению |
|---|--------|-----------------|-----|----------------------------|
| 1 | ... | 85 000 | ВЧ | Title, H1, первый абзац |
| 2 | ... | 4 200 | СЧ | H2, мета-описание |
| 3 | ... | 280 | НЧ | Тело статьи, FAQ |

**Классификация:**
- **ВЧ** (высокочастотные): > 5 000 показов/мес
- **СЧ** (среднечастотные): 500–5 000
- **НЧ** (низкочастотные): < 500

Фразы с нулевой частотностью — упомянуть отдельно, не включать в таблицу (слишком длинный хвост, опечатка или нет спроса).

**Расширенный блок** (если просили тренды или регионы):
- Тренд: пиковые месяцы + вывод о сезонности
- Регионы: топ-5 городов / регионов по доле спроса

## Форматы вывода

- **Базовый** (по умолчанию): таблица + рекомендации + находки из расширенной семантики
- **Расширенный** («с трендами», «подробно», «с сезонностью»): + тренды, + регионы
- **Быстрый** («только ключи», «список», «быстро»): нумерованный список фраза → частотность

## Финальный quality gate

Перед выдачей результата применить по отдельности критерии `evals/shared.csv` и `evals/skill-specific.csv` по инструкции `evals/judge_prompt.md`. Не считать общий балл. `N/A` не считать провалом. Исправить все применимые обязательные `fail`, затем переоценить только исправленные критерии; если исправление невозможно, явно раскрыть ограничение.

## Переносимость и запуск

Пути к ресурсам ниже относительны корню установленного навыка. Перед запуском
определи этот корень через механизм платформы; не предполагай текущую папку.
Относительные примеры CLI разрешай в абсолютный путь к скрипту, сохраняя рабочую
папку результата отдельно. Переменные и механизмы конкретной платформы задаются
её адаптером, не являются зависимостью универсальной методологии. Без Python, сети или коннектора запросить нормализованный вход или
вернуть ограниченный результат с явным статусом «не проверено».

Здесь capability обозначает возможность, а не гарантированное имя MCP-команды.
Вызовы в примерах — схема: сначала прочитать объявленные инструменты и сопоставить
аргументы. Не устанавливать зависимости, не создавать расписания, не публиковать
и не отправлять сообщения без применимого разрешения пользователя.
